## What it is

Merchants selling on Salla, Zid, and WhatsApp end up with customers spread across several inboxes, and with their catalogue, orders, and customer history somewhere those inboxes cannot see.

Tajeer AI closes that gap. Every conversation lands in one place. An assistant answers from the merchant's own products, prices, stock, and order status. A person on the team takes over the moment the conversation needs one.

One deployment serves many merchants. Each merchant has their own stores, channels, team, and data.

## Capabilities

| Area | What it does |
| --- | --- |
| **Unified inbox** | Every channel in one conversation view, with assignment, tags, filters, saved views, internal notes, and handoff between the assistant and a person |
| **Assistant** | Answers grounded in the merchant's catalogue, knowledge, stock, and orders |
| **Store sync** | Salla and Zid: catalogue, orders, customers, and carts stay in step with the conversation |
| **Channels** | WhatsApp, Messenger, Instagram, a website chat widget, and email |
| **Customers** | Profiles, segments, sales stages, and follow-up on carts that were left behind |
| **Campaigns** | Newsletters and broadcasts, with subscription and consent |
| **Automation** | Flows and rules that run when no one from the team is in the conversation |
| **Administration** | Tenants, plans, features, invoices, and subscriptions |
| **Mobile** | An app for people handling conversations away from the desk |

## How it fits together

```text
Channels  →  one inbox  →  assistant, grounded in the store
                ↓
         a person on the team, when the conversation needs one
```

The store stays the source of catalogue, price, stock, and order status. The inbox is where the customer is. The assistant sits between them, and a teammate can step in without losing the thread.

## Technology

The product is a web application for merchants and their teams, a service that runs the conversations and the store sync, and a mobile app for agents. The public website is [tajeerai.com](https://tajeerai.com).

## Status

Tajeer AI is a live product. This repository is the public project page.

The production source code is private and proprietary. This repository does not contain the application, it does not accept contributions to the product source, and it is not a distribution you can run yourself.
